# Cívica MA — Eleições 2026

Painel independente para consulta organizada a dados públicos das Eleições Gerais de 2026 no Maranhão.

## Dados
- Candidaturas: TSE / DivulgaCandContas (consulta em tempo de execução).
- Zonas e seções: TSE / Portal de Dados Abertos, “Perfil do eleitorado por seção eleitoral - 2026 - MA”.
- Municípios: códigos IBGE dos 217 municípios do Maranhão.

O projeto não é um sistema oficial do TSE/TRE-MA e não apresenta apuração, resultado ou projeção eleitoral antes da publicação oficial desses dados.

## Executar
```bash
npm start
```
Abra `http://localhost:4173`.
